# PGE385K_hw_project_2_repository
Collection of all plotting code utilized in homework project 2 that were generated with the assistance of artificial intelligence. As prompted in class, plotting not done in UTAPWeLS was executed through collaboration with artificial intelligence platforms for optimization of workflows and increasing plotting quality/readability. Plotting codes were generated from detailed prompting based on desired outcomes and project requirements.

1. HA2_basic_analyis.ipynb: Basic well-log panels, core measurement, and core-property comparisons
   
2. HA2_intro_figures.ipynb: INtroduction figures: quality checks, zonation, water-sand detail, and crossplots
   
3. HA2_ThK_reproduction.ipynb: Updated Th-K, PE-Th/K mineral-indicator plots
   
4. HA2_interpretation.ipynb: Preliminary inversion, porosity/core comparisons, and initial Thomas-Stieber diagnostics
